UItem — External Resource Packs (ItemsAdder / Oraxen style)
==========================================================

Place folders or .zip files here. They are merged when you run:
  /uitem rp build
  /uitem rp generate
  /uitem rp gui  →  BUILD PACK

Examples:
  packs/import/MyServerPack.zip
  packs/import/OraxenExtra/

UItem items are added on top (custom_model_data overrides).
Put item textures in: plugins/UItem/textures/<item_id>.png
